# Support Command Center
### Follow a customer issue from ticket to diagnosis.

A technical support engineering interface that brings customer tickets, SQL diagnostics, query-plan analysis, data validation, and service monitoring into one workspace.

## What to explore
1. Select a customer ticket.
2. Inspect the related SQL diagnostic workspace.
3. Run the simulated diagnostic flow.
4. Review query-plan findings and recommended fixes.
5. Compare source and dashboard metrics and inspect revenue visualization.

**Stack:** HTML · CSS · JavaScript

## Run
Open [index.html](index.html) in a browser. No backend, installation, or credentials are required.

## Engineering story
The project demonstrates how a support workflow can expose technical evidence alongside a customer issue, making troubleshooting easier to explain and hand off.

## Scope & data
Independent portfolio prototype inspired by analytics support workflows. Tickets, monitoring metrics, diagnostics, and query outcomes are simulated. This app does not connect to a live SQL warehouse or monitoring platform and is not an official Sigma product.
